# Lessons from real runs (read before ranking)

Each line is a mistake made in real matchmaking, and what to do instead. Add your own.

1. **Brand logo ≠ core skill.** A candidate with years at a crypto company was shortlisted for a Head of Security role, but their work was corporate IT (laptops, SSO, office network), not production infrastructure. Client QA rejected it. → Check the core skill first; a relaxed bar relaxes the boxes, not the skill.
2. **A one-day repo is not depth.** 140+ commits on a single day, with a coding-test PDF and AI-agent files in the repo = a take-home test built with AI. → Look at commit-date spread and repo contents, not language bytes.
3. **Small merged PRs ≠ "strong in X".** A few merged dependency-upgrade PRs prove "has written X", not "X specialist". Say which one you proved.
4. **Forks-only GitHub can't verify anything.** "Runs 20+ services in Go" with only forks on GitHub → mark 🟡/? and ask for samples.
5. **Inflow hides in secondary fields.** Job-link applicants and scout submissions can land in a "PTF copy" field instead of Self-Applied; strong people sat there for weeks. → Read every inflow field.
6. **Someone else may have changed the pipeline.** Shortlists get edited by teammates. → Re-read stage fields right before writing, and flag surprises.
7. **Overlapping "current" jobs = fraud signal.** E.g. Senior Director + substitute teacher + own firm, all "present", with copy-pasted bullets. → Flag before anyone contacts them.
8. **More than one short stint (< ~12 months, self-employed included) = orange/red flag.** Ask why (acquisition, startup closing) before rejecting.
9. **Random-looking LinkedIn skill endorsements = scam signal.** Needs a human browser check.
10. **Agents overstate.** A subagent marked "Go ✅" from CV lines. → Spot-check one key claim per pick yourself.
11. **Portal salary defaults are not asks.** A form's default range ("40k–200k") says nothing.
12. **Human quality scores can be off both ways.** A low-rated profile can be the best JD fit; many high ratings are brand-driven. Treat the score as ~80% signal and explain disagreements.
